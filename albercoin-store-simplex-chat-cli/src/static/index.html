OPCIONAL

Conecta Hermes u otro cliente

SimpleX funciona por sí solo. Al activar este conector, un cliente de confianza puede utilizar su API.

Las credenciales dan control sobre esta identidad SimpleX y sus conversaciones. Usa el conector dentro de la red de Umbrel; para otro equipo, configura un túnel o TLS.

Hermes Agent de Umbrel

1. Acepta tu contacto en SimpleX. 2. Activa el conector. 3. Indica los ID de los contactos autorizados. 4. Descarga la configuración y aplícala con las instrucciones incluidas en el paquete.

Los ID aparecen en la lista de conversaciones. No son nombres de usuario. Los grupos quedan desactivados en la configuración exportada.

El archivo contiene credenciales: guárdalo en privado. La app no modifica Hermes automáticamente.

Una copia completa de tu identidad

Incluye bases de datos, archivos y configuración. SimpleX se detiene brevemente para obtener una copia consistente y vuelve a arrancar después.

Las copias contienen claves y mensajes. Sin una clave pública age configurada no se cifran adicionalmente. Conserva copias y claves privadas fuera del nodo. Desinstalar la app puede borrar su volumen.

La restauración se realiza con la app detenida. Consulta el procedimiento del README. Las copias locales con más de 10 días se eliminan automáticamente.

Cómo funciona y qué necesita Hermes
Panel web → gestor de órdenes → SimpleX CLI → servidores SMP → contacto. El panel consulta el historial cada 4 segundos mientras está visible. El estado «Cliente local conectado» solo confirma el enlace interno.
Para empezar: crea tu dirección en «Perfil y contactos», ábrela desde tu móvil y acepta aquí la solicitud. Después selecciona el contacto en «Conversaciones» y prueba mensajes en ambos sentidos.
Datos para Hermes
En «Integraciones», activa y guarda el conector. Copia la URL privada completa en SIMPLEX_WS_URL. No uses tu dirección pública ni el QR. En SIMPLEX_ALLOWED_USERS pon el ID numérico de tu móvil que aparece en Conversaciones. En SIMPLEX_HOME_CHANNEL usa ese mismo ID para notificaciones.
La configuración descargada mantiene SIMPLEX_ALLOW_ALL_USERS=false, SIMPLEX_AUTO_ACCEPT=false y grupos desactivados. El archivo se aplica con el asistente de integrations/hermes/README.md; no es una importación automática de la interfaz de Hermes. Habilita el canal SimpleX y reinicia Hermes después. Hermes necesita su proveedor de modelos configurado.
La URL usa el nombre interno del contenedor y el puerto 2192: Hermes debe poder alcanzarlos desde su red Docker. Si el contador de clientes sigue a cero, revisa la configuración y la conectividad. Si conecta pero no responde, revisa los IDs autorizados, los registros del conector y los de Hermes.
