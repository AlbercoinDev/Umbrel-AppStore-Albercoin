¿Qué necesito para clearnet?

Dominio o IP pública accesible y TCP 5223 permitido en el firewall y redirigido hacia Umbrel desde el router. Puedes usar DNS dinámico si tu IP cambia. Con CGNAT necesitas una solución adicional para conexiones entrantes. No necesitas abrir 80/443 ni Let's Encrypt para el transporte SMP. Clearnet utiliza TLS, pero no oculta la IP del servidor. Esta app no configura tu router.

El puerto externo de esta versión es fijo: 5223. Solo se aceptan dominios e IPv4; IPv6 directo queda pendiente.

Desmarcarlo permite a terceros crear colas y consumir recursos. La contraseña SMP no es la contraseña del panel.

Aplicar reinicia SMP de forma controlada. Conserva certificados e identidad onion. Si cambia la dirección, actualízala en tus clientes.

Identidad y copias

Conserva una copia offline de configuración, certificados y estado con la app detenida. La clave ca.key permite renovar certificados: custódiala fuera del nodo. No se elimina automáticamente. Desinstalar la app puede borrar todos sus datos.
