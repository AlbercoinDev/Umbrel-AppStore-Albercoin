OPCIONAL

Conecta Hermes u otro cliente

SimpleX funciona por sí solo. Al activar este conector, un cliente de confianza puede utilizar su API.

Las credenciales dan control sobre esta identidad SimpleX y sus conversaciones. Usa el conector dentro de la red de Umbrel; para otro equipo, configura un túnel o TLS.

Hermes Agent de Umbrel

1. Acepta tu contacto en SimpleX. 2. Activa el conector. 3. Indica los ID de los contactos autorizados. 4. Descarga la configuración y aplícala con las instrucciones incluidas en el paquete.

Los ID aparecen en la lista de conversaciones. No son nombres de usuario. Los grupos quedan desactivados en la configuración exportada.

El archivo contiene credenciales: guárdalo en privado. La app no modifica Hermes automáticamente.

Una copia completa de tu identidad

Incluye bases de datos, archivos y configuración. SimpleX se detiene brevemente para obtener una copia consistente y vuelve a arrancar después.

Las copias contienen claves y mensajes. No se cifran adicionalmente: protégelas y conserva otra copia fuera de este nodo. Desinstalar la app puede borrar su volumen.

La restauración se realiza con la app detenida. Consulta el procedimiento del README. Las copias no se borran automáticamente.

Red y servidores

Deja los campos vacíos para utilizar los valores predeterminados de SimpleX.

El proxy debe ser accesible desde el contenedor. Configurarlo no instala Tor ni garantiza por sí solo una política de tráfico exclusivamente onion.
